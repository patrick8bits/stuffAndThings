# Stuff and Things

An interactive Go engineering portfolio featuring three
demonstrations of algorithms and backend infrastructure.

## Features

- Sorting Visualizer — Bubble, Insertion, and Quick Sort
- CDN Health Monitor — Concurrent HTTP health checks
- CDN Cache Simulator — LRU caching and request coalescing

## Technologies

Go, HTML, CSS, JavaScript, REST APIs, Docker,
GitHub Actions, Ansible, and NGINX.

```shell
go run ./cmd/server
